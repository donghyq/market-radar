# Market Radar 0.3.0 开发计划

## 主要功能

- **用已有渠道采集样本。** 首选 App Store 等现有免登录渠道，用自动化脚本采集。直接使用采到的应用、评论和源站时间，保留证据 ID 和来源链接。
- **增加「产品聚合图」标签页。** 用桑基图展示 **市场信息 → 产品形态 → 用户画像、用户反馈或竞品线索**。按用途和需求归组，切换图的末端维度，每条流带按对应记录数计量。
- **从图回到证据。** 可以由产品形态查看关联信号、来源、用户反馈及同类应用线索。用户画像采用有依据的字段，缺失显示「未知」。应用线索保留应用 ID 和商店链接。

## 开发边界

- 首轮用现有免登录采集结果直接生成图，使用规则归组。延续增量入库、去重、历史证据 ID 和现有评论的本地导出边界。
- 0.3.0 当前处于规划阶段。开发、测试和发布另行安排。

## 验收

用一批 App Store 实采样本核对产品分组、流带计数和源站链接。每个视图内同一记录只计一次，缺少画像字段时能看出覆盖情况。现有信号库仍可打开对应证据。
