# Market Radar 0.3.0 开发计划

## 共用数据与分组

- 首选 App Store 等现有免登录渠道，用自动采集得到的应用、信号、评论和源站时间作为样本，保留证据编号和来源链接。
- 两个标签页共用同一套产品与品类分组。先用源站产品 ID、名称和别名归并同一产品，再按正文、用途和需求标签归类。评论沿关联信号入组，归属不明确的记录标为待分类。

## 两个标签页

### 产品聚合图

用桑基图展示 **市场信息 → 产品形态 → 用户画像、用户反馈或竞品线索**。可切换末端维度，同一视图内每条记录只计一次，流带宽度按记录数计量。点击产品形态可看关联信号、评论和同类应用，保留应用 ID、来源链接和证据编号。用户画像依据原文或平台字段填写，展示字段覆盖情况，缺失显示「未知」。

### 市场热度

按日或按周展示趋势，可切换品类或具体产品。横轴为源站时间，纵轴为各曲线去重后的记录或事件数。

- **讨论热度**统计相关发帖和评论。
- **需求热度**统计规则库认定的独立需求证据，如求购、询价、使用痛点和付费反馈。
- **生产热度**统计可核实的产品上架、版本发布及线上服务发布事件。

悬停显示该时段、热度类型、计数和主要贡献产品或品类。点击数据点可查看对应信号、评论或发布记录及其来源。缺少源站时间的记录标为「时间待核实」，采集缺口用断点或标记显示，有覆盖且无记录的时段显示为 0。

## 开发边界

- 首轮用现有采集结果和规则生成两张图。延续增量入库、去重和历史证据 ID，评论明细随本地看板导出。
- 0.3.0 当前处于规划阶段。开发、测试和发布另行安排。

## 验收

用一批 App Store 等渠道的实采信号和评论，核对两个标签页的产品分组、桑基流带和三条曲线的计数。重复导入同一批数据后计数保持一致。抽查画像缺失、采集缺口和零记录的展示，并从桑基图节点和热度曲线数据点回到信号库及源站证据。
